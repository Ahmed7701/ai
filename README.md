# HVAC DXF Routing Scripts

Utilities for adding schematic chilled-water pipe routes and supply-air duct layouts to an existing DXF plan.

> **Engineering note:** The coordinates and sizes in these scripts are explicit assumptions read from one reference plan. They are not design calculations and must be reviewed by a qualified HVAC engineer before use in construction documents.

## Included scripts

- `hvac_pipes.py` adds chilled-water supply and return routes (`CHWS` / `CHWR`) to a copy of an input DXF.
- `hvac_ducts.py` adds supply-air ducts, diffusers, an AHU outline, and labels to a DXF. It can be run on the output generated by `hvac_pipes.py` to create a combined drawing.
- `out/` contains committed DXF snapshots from the original change for reference. New generated files should be written elsewhere or with a `.generated.dxf` suffix.

## Requirements

- Python 3.9 or newer
- `ezdxf` for reading and writing DXF files
- `shapely` for merging duct geometry

Set up an isolated environment:

```bash
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows PowerShell: .venv\\Scripts\\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Usage

The scripts take an input DXF and an output DXF. The input is never overwritten.

```bash
python hvac_pipes.py input.dxf out/pipes.generated.dxf
python hvac_ducts.py out/pipes.generated.dxf out/pipes_ducts.generated.dxf
```

The scripts create these layers when they are missing:

- Pipes: `P-CHWS`, `P-CHWR`, `P-CHW-TXT`
- Ducts: `M-DUCT-SA`, `M-DIFUSER`, `A-SUP-texts`, `M-AHU`, `A-RET-texts`

The current geometry uses drawing units interpreted as metres. Adjust the coordinate constants in each script for a different plan, and verify the resulting routes visually in a CAD application.

## Validation

Run the syntax checks and the end-to-end smoke test locally:

```bash
python -m py_compile hvac_pipes.py hvac_ducts.py
python -m unittest discover -s tests -p 'test_*.py' -v
```

GitHub Actions runs the same checks for pushes to `main` and pull requests targeting `main`.

## Review checklist before production use

1. Confirm the input plan units, origin, and coordinate assumptions.
2. Check pipe and duct clearances, crossings, connections, and equipment locations in CAD.
3. Confirm sizes and airflow/water-flow calculations against the project requirements.
4. Review generated DXF layers and labels with the project CAD/BIM standards.
5. Keep generated DXF snapshots only when they are useful review artifacts; prefer reproducible generation for routine outputs.
